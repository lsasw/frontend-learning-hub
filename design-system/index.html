DESIGN PHILOSOPHY

设计理念：开发者优先

DevPortal 2.0 采用 「开发者优先」的设计语言，参考 Linear、Vercel、GitHub 等一线开发者工具的视觉风格。 核心原则：高信息密度、低视觉噪音、键盘可操作、暗色原生。 目标是让 5 年+经验的开发者用户在 3 秒内找到目标教程。

✓ 设计原则

信息密度优先：紧凑布局，减少空白浪费，单屏可见更多内容

✓ 设计原则

键盘驱动：Cmd+K 搜索、方向键导航、Esc 返回，全键盘可达

✓ 设计原则

暗色原生：深色模式不是附属功能，而是与浅色同等优先的一等公民

✓ 设计原则

专业图标系统：统一 SVG 线条图标，弃用 emoji，保持视觉一致性

COLOR SYSTEM

色彩系统

采用 Zinc 灰阶 + Blue 主色 + Purple 点缀 的三层色彩体系。 所有颜色通过 CSS 变量定义，支持明暗双主题无缝切换。 色彩对比度全部满足 WCAG AA 标准（正文 4.5:1，大字 3:1）。

TYPOGRAPHY

字体系统

双字体体系：Inter（正文/UI） + JetBrains Mono（代码/数据）。 字号采用 14px 基准，比传统 16px 更紧凑，适合开发者的高密度信息阅读习惯。 字重控制在 400/600/700 三档，避免视觉碎片化。

LAYOUT STRUCTURE

页面布局结构

三栏式布局：顶栏（56px） + 侧边栏（240px） + 主内容区（弹性）。 顶栏放置全局搜索和主题切换，侧边栏放置分类导航，主内容区按分类区块组织卡片网格。

布局变更：侧边栏从 250px→240px（更紧凑）；顶栏从 54px→56px（容纳搜索框）；首页从居中 Hero 改为左对齐信息流，提升信息密度。
/* 布局尺寸 token */ --topbar-h: 56px; /* 顶栏高度 */ --sidebar-w: 240px; /* 侧边栏宽度 */ --content-max: 1280px; /* 内容区最大宽度 */ /* 顶栏布局 */ .topbar { height: var(--topbar-h); display: flex; align-items: center; gap: var(--sp-4); padding: 0 var(--sp-6); } /* 三栏弹性布局 */ .page-layout { display: flex; } .side-nav { width: var(--sidebar-w); flex-shrink: 0; } .content { flex: 1; max-width: var(--content-max); }
INTERACTION PATTERNS

交互流程设计

核心交互围绕「搜索 → 浏览 → 进入」三步路径设计。 新增 Cmd+K 命令面板、键盘方向键导航、主题快速切换三大交互能力。

RESPONSIVE STRATEGY

ACCESSIBILITY

无障碍标准

全面遵循 WCAG 2.1 AA 标准，确保所有用户均可高效使用。

色彩对比

正文 ≥4.5:1，大字 ≥3:1。明暗模式均通过验证。

键盘可达

所有交互组件可通过 Tab 键访问，焦点环清晰可见。

触控目标

移动端可交互元素 ≥44×44px，间距充足防误触。

语义化

使用语义化 HTML 标签 + ARIA 标签，屏幕阅读器友好。

动画偏好

尊重 prefers-reduced-motion，降低动画幅度。

文字缩放

支持浏览器 200% 文字缩放，布局不溢出。

DEVELOPER HANDOFF

开发标注与交接

所有设计 Token 以 CSS 变量形式定义在 :root 中。 开发团队可直接复制 :root 块到项目中，所有组件样式引用这些变量即可实现主题切换。

实施优先级：① 定义 CSS 变量 → ② 替换硬编码颜色 → ③ 实现顶栏搜索 + Cmd+K → ④ 实现暗色模式 → ⑤ 替换 emoji 为 SVG 图标 → ⑥ 响应式适配
